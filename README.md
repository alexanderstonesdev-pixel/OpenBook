# OpenBook

Lettore di ebook Android con traduzione integrata, pensato per chi legge libri in lingua originale mentre impara una lingua.

## Funzionalità

- 📖 Lettore EPUB con sfogliamento a pagine
- 🌍 Traduzione istantanea di parole e frasi, on-device (nessun testo inviato a server esterni durante l'uso)
- 📓 Glossario personale con flashcard per ripassare le parole salvate
- 🏋️ Esercizi: completa la frase, vocabolario illustrato, ascolto
- 🔊 Audiolibro: lettura ad alta voce continua, pagina dopo pagina
- 🎨 Temi di lettura (chiaro, scuro, seppia), font e dimensione regolabili
- 📚 11 classici della letteratura inglese inclusi

## Privacy

Nessun account, nessun server gestito da noi. Tutti i dati restano sul dispositivo. Informativa completa: [Privacy Policy](https://alexanderstonesdev-pixel.github.io/OpenBook/)
